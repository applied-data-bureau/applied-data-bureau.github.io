Zadatak je bio da se prema gotovom dizajnu napravi jednostranični sajt sa formom za prijavu.

Rezultat: demo stranica.

Dodatno unapređenje (iako nije eksplicitno traženo): uvedena je logika za ispravne jezičke oblike pri dinamičkom prikazu broja sati.

function plural(n, form1, form2, form5) {
  n = Math.abs(n) % 100;
  var n1 = n % 10;
  if (n > 10 && n < 20) return form5;
  if (n1 > 1 && n1 < 5) return form2;
  if (n1 == 1) return form1;
  return form5;
}

Za formatiranje unosa korišćena je biblioteka formatter.js.
