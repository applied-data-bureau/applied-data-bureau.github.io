--- layout: post title: "Param metoda u Mojolicious-u kroz verzije" type: post excerpt: "Praktična migraciona beleška: iteracija parametara je promenjena u Mojolicious 6, pa stari kontrolerski kod traži ispravku." ---

Kod koji se prenosi iz projekta u projekat može neočekivano da pukne kada se promeni ponašanje framework-a. To se desilo sa iteracijom parametara u Mojolicious kontrolerima.

U starijim projektima često se koristio ovakav obrazac:

# Mojolicious pre verzije 6
foreach ( map { (/^count-(\d+)/) } $self->param ) {
  ...
  $self->param("count-$_")
  ...
}

Od Mojolicious 6 pristup je praktično zamenjen. Ispravan oblik:

# Mojolicious verzija 6+
foreach ( map { (/^count-(\d+)/) } @{$self->req->params->names} ) {
  ...
  $self->param("count-$_")
  ...
}

Reference: Mojolicious commit.
