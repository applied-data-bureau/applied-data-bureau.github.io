Task

The goal was to build a bot that collects ticket prices from S7. The workflow was: choose route/date, submit search, read the flights table, and save minimum fares with flight numbers.

The tricky part: flight lists could change from day to day, so the parser had to track real flight identifiers instead of relying on row order.

Source: weblancer.net

Approach

I split the problem into four parts:

1) request and session handling
2) parsing response HTML
3) execution logic for daily runs
4) readable output for users

Data Retrieval

The search page was at http://ibe.s7.ru/S7/webqtrip.html. I reproduced browser behavior with Perl and preserved request flow state.

  • #!/usr/bin/perl
  • use strict;
  • use LWP::UserAgent;
  • my $url = 'http://ibe.s7.ru/S7/webqtrip.html';
  • my %post_params = (
  • origin => 'MOW',
  • destination => 'UFA',
  • departureDate => '2009-08-05',
  • cabinClass => 'E', # E - economy, B - business
  • journeySpan => 'OW', numAdults => '1',
  • );

Parsing

After getting the HTML, I extracted flight rows and fare blocks via tag-based lookup and mapped each fare type to a route instance.

This produced a structured output table with flight number + minimum fare per date.
