Jekyll is a modern static site generator that builds lightning-fast pages without databases or server-side logic. A strong fit for portfolios, blogs, documentation sites, landing pages, and promo websites.

Why Jekyll?

  • Loading speed - static HTML pages are 5-10x faster than dynamic sites
  • Strong security - no PHP, no database attack surface, fewer vulnerabilities
  • Free hosting - deploy to GitHub Pages, Netlify, or Vercel with no monthly fees
  • SEO out of the box - clean markup and structure for better search visibility
  • Low maintenance - no CMS plugin updates and less security overhead
  • Markdown content - easy text editing without deep HTML knowledge

What is included:

  • Technical implementation: responsive design for all devices, up to 10 pages, clean HTML/CSS, and navigation setup.
  • Optimization
  • SEO setup
  • Hosting: deployment to GitHub Pages / Netlify / Vercel, auto-deploy pipeline, all code in your repository, full independence from the contractor.

  • Project description: website goal, target audience, primary tasks
  • Content: texts, images, logos (or I can help select them)
  • References: websites whose design you like
  • Structure: list of pages and sections
  • (Optional) Domain name if you plan to connect one
