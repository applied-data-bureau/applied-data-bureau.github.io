--- layout: post title: "Mojolicious Param Method Across Versions" type: post excerpt: "A practical migration note: parameter iteration changed in Mojolicious 6, so old controller snippets need an update." ---

Code copied between projects can break unexpectedly when framework behavior changes. This happened with parameter iteration in Mojolicious controllers.

In older code, all incoming parameter names were commonly iterated like this:

# Mojolicious before version 6
foreach ( map { (/^count-(\d+)/) } $self->param ) {
  ...
  $self->param("count-$_")
  ...
}

In Mojolicious 6 this approach was removed from the docs and effectively replaced. Updated iteration:

# Mojolicious version 6+
foreach ( map { (/^count-(\d+)/) } @{$self->req->params->names} ) {
  ...
  $self->param("count-$_")
  ...
}
