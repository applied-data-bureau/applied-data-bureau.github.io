The task was to build a one-page site from a provided design with a lead form.

Resulting layout: demo page.

An additional quality improvement was added even though it was not required: correct plural forms for dynamic hour values (to avoid grammatically wrong labels).

function plural(n, form1, form2, form5) {
  n = Math.abs(n) % 100;
  var n1 = n % 10;
  if (n > 10 && n < 20) return form5;
  if (n1 > 1 && n1 < 5) return form2;
  if (n1 == 1) return form1;
  return form5;
}

I also used formatter.js for input formatting in the form fields.
