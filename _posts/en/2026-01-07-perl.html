I will migrate your Perl system to a new server or hosting environment carefully, safely, and with full functionality checks. Suitable for legacy projects with manual dependencies, custom modules, and outdated environments.

What I do:

  • Complete migration of a Perl project to a new server
  • Environment setup: Perl, modules, CPAN, XS libraries
  • Database migration and setup (PostgreSQL / MySQL)
  • Apache/nginx, ModPerl, and CGI configuration
  • Fixing compatibility issues (Perl versions, modules, paths)
  • Post-migration diagnostics and testing
  • Configuration optimization (optional)

I work with:

  • Old and modern Perl versions
  • Projects without documentation
  • Custom frameworks, CGI monoliths, mixed Perl + PHP + JS stacks
  • Linux servers, shared hosting, VPS, Docker

Why me:

  • I have migrated legacy projects with 10-20 years of history
  • I assess risks upfront and propose a safe migration plan
  • I can adapt projects to modern runtime versions
  • I fix related issues discovered during migration

Needed to start:

  • Access to old and new servers (SSH/panel).
  • Project copy or repository.
  • Environment details (Perl version, web server, DB).
  • What must work after migration (list of pages/functions).
Important:

Complex systems require a preliminary assessment.

Work cannot start without access or task details.
